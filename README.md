# 🏦 Magang Pegadaian - Payment Reminder App (Frontend)

Repositori ini berisi antarmuka pengguna (*Frontend Web Application*) untuk proyek **Payment Reminder App** yang dikembangkan selama masa program magang di **PT Pegadaian**.

---

## 📌 Deskripsi Proyek
Aplikasi web ini dirancang untuk membantu sistem pengingat pembayaran (*payment reminder*) dengan menyediakan antarmuka pengguna yang responsif, intuitif, dan mudah digunakan. Terdiri dari beberapa modul utama seperti autentikasi pengguna, ringkasan dashboard, serta manajemen data.

---

## ✨ Fitur Utama
* **🔐 Halaman Autentikasi (`login.html`):** Tampilan login terstruktur dengan validasi input berbasis JavaScript.
* **📊 Dashboard Utama (`dashboard.html`):** Panel kontrol visual untuk menampilkan ikhtisar statistik dan pengingat pembayaran.
* **📋 Manajemen Data (`data.html`):** Penyajian data tabel yang dinamis untuk melihat status dan daftar tagihan/pembayaran.
* **📱 Desain Responsif:** Tampilan yang menyesuaikan dengan baik di perangkat desktop maupun seluler.

---

## 🛠️ Teknologi yang Digunakan
* **HTML5:** Struktur dasar halaman web.
* **CSS3 & Bootstrap:** Pemformatan tata letak (*layouting*), responsivitas, dan styling komponen kustom.
* **Vanilla JavaScript (Native JS):** Logika manipulasi DOM, penanganan event, serta interaktivitas antarmuka tanpa framework JS tambahan.
